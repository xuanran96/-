# Web 版验证记录

范围已按用户新指令调整为独立 Web 版，不再将原 KMES 源码作为本轮实施前提。原系统接入另行实施。

已实现：四页导航、商品资料新增、库位新增、组合筛选、分页、地图定位、登记防重与草稿恢复、单条/批量移位、异常库位处理、任务预留、波次调整、取消释放、拣货与条码/数量复核、轨迹、CSV 导出和 Code128 标签/拣货单打印。

已验证：TypeScript 检查通过；7 组领域流程测试通过；本地真实 D1 API 集成测试通过。实际验证包含重复请求和重复箱号、移位库存守恒与失败不变更、容量上限、异常库位、超量预留、并发争抢、错码复核拒绝、正式出库扣减、轨迹重新读取及跨来源请求拒绝。

最终生产构建成功，Worker 导出 fetch 入口。构建版本曾在本地启动，首页 HTTP 200；指定同一持久化目录后，API HTTP 200，能读取另一服务进程保存的 QA 记录。QA 记录只在本地库，发布迁移仅建表，无测试记录或示例数据批量写入迁移。

未验证：浏览器逐按钮交互、实物扫码枪、摄像头、实际标签打印机。浏览器预览连接初始化失败，错误为插件内部 browser-service.mjs 缺失；未使用其他自动化方式绕过。页面 HTTP 渲染成功不等同于完整浏览器验收。WebMCP 查询工具已按 feature detection 注册；当前无可用验证上下文，未声称验证通过。

运行边界：单所有者私有站点，无原系统企业账号、仓库级权限或真实员工身份审计；初始数据是示例。D1 单状态记录采用版本比较更新，适合本轮独立工作台，正式生产接入需使用原库存事务和关系数据模型。数量单位为整数件，暂无面料小数单位和整箱唯一复核。详细限制及启动方式见 README。

依赖安装器报告 14 项审计告警（6 moderate、8 high），本轮保留受支持脚手架版本，未使用强制升级改变框架版本。企业正式上线前需专项评估与升级回归；本轮不声称完成生产安全验收。
