# 中文格式规范

## 基本原则

- 面向使用者的说明默认使用简体中文，表达直接、具体、可执行。
- 技术标识符、文件名、路径、命令、代码、Skill 名称和行业通用缩写保留原文。
- 同一概念使用同一个名称，不在“任务、事项、工作项”等近义词之间随意切换。
- 备注用于补充限制、例外和背景，不重复正文已经明确的内容。

## 标题与段落

- 文档只保留一个一级标题，章节从二级标题开始。
- 标题不添加句号，避免使用“相关说明”“其他内容”等含义模糊的名称。
- 一个段落表达一个主题；步骤使用有序列表，并列事项使用无序列表。
- 表格用于字段对应和固定检查项，不把长篇说明塞进表格。

## 标点与空格

- 中文句子使用全角标点：`，。；：！？（）`。
- 文件名、命令、参数和代码使用反引号，例如 `README.md`、`python -m pytest`。
- 中文与行内英文、数字之间保留一个半角空格，例如“使用 AI 完成 3 次验证”。
- 英文缩写与中文标点之间不额外加空格，例如“生成 PR 描述。”
- 日期统一写成 `YYYY-MM-DD`，版本号统一写成 `v1.2.0` 或项目声明的格式。

## 备注说明

统一使用下面的格式：

```markdown
## 备注说明

- 说明适用范围、限制、例外或仍待确认的内容。
- 不记录密码、密钥、Cookie、个人隐私或敏感业务正文。
```

没有实际备注时删除整个章节，不写“无”或保留空标题。
