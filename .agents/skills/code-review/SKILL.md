name: code-review
description: 审查代码变更中的正确性、回归、安全、并发、边界条件和测试缺口，并按严重程度输出可定位的问题。用于提交、分支、PR 或工作区变更评审；不用于没有变更范围的泛泛代码建议。
---

# 目标

找出会造成错误行为、数据风险、安全问题或兼容性破坏的具体缺陷。

# 必要输入

- 明确的变更范围及项目规则；缺省时审查当前工作区差异。

# 执行步骤

1. 读取适用规则，确认基线、变更范围和用户已有修改。
2. 理解修改意图、调用方、公共契约和相关测试。
3. 检查成功、失败、边界、并发、权限、数据保留和兼容路径。
4. 只报告有代码证据、可触发且值得修复的问题。
5. 检查测试能否覆盖发现的风险，并避免把历史存量混入本次结论。

# 约束

- 发现按严重程度排序，先写问题再写摘要。
- 每条必须包含文件、紧凑行号范围、触发条件和实际影响。
- 不把风格偏好描述成缺陷；没有发现时明确说明剩余验证范围。

# 输出格式

- 严重级别、标题
- 文件和行号
- 触发条件与影响
- 建议修复方向

# 备注说明

- 问题标题和影响说明使用简体中文，文件路径、符号和严重级别保留原文。
- 没有可操作问题时不制造备注，只说明已审查范围和剩余验证限制。
