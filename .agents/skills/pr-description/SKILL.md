# 目标

生成与实际变更一致、便于评审和发布判断的 PR 描述。

# 必要输入

- 基线与当前差异、提交记录、测试结果和项目 PR 模板。可从仓库读取时不要求用户重复提供。

# 执行步骤

1. 确认比较基线和 PR 范围，区分相关变更与用户已有无关修改。
2. 从差异归纳问题背景、行为变化、实现边界和复用内容。
3. 提取真实执行过的测试、构建、截图或手工验证；未执行项明确标记。
4. 识别兼容性、迁移、安全、配置、发布和回滚风险。
5. 遵循仓库已有 PR 模板和术语，删除空章节与重复描述。

# 约束

- 不声称未执行的验证已通过。
- 不根据提交标题代替阅读实际差异。
- 不包含密钥、内部凭证、个人数据或无关改动。

# 输出格式

- 背景
- 修改内容
- 验证方式与结果
- 截图或可见变化
- 风险、兼容性与回滚方案

# 备注说明

- PR 正文默认使用简体中文，提交号、文件名、命令和技术标识符保留原文。
- 不适用的章节直接删除，不填写“无”来制造形式完整。
