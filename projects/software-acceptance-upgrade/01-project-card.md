# 项目卡：软件验收与目标完善

- 项目 ID：software-acceptance-upgrade
- 质量等级：Q2
- 谁会使用：提供代码或程序及最终目标的普通使用者。
- 用户最终目标：在现有验收项目中增加代码和程序验收，且主动完善到最终目标。
- 本次包含：更新 AI 执行流程、技能与项目模板；提供验收执行工具、证据记录、示例和测试。
- 明确不做：独立模型托管服务、自动生产发布、不受限制的无人值守执行。
- 授权依据：用户已明确要求优化和增加能力，直接推进本地实现。

## 验收口径

1. AI 入口明确要求检查源码、运行程序、补齐功能、修复与复测，不止输出问题清单。
2. 工具将目标条件映射到实际命令，保留每轮证据，能够检测错误退出码与输出不符合预期。
3. 超时、命令缺失和待人工确认均不能误报为自动通过；无运行检查或不完整配置不能执行。
4. 真实示例能够运行，测试覆盖失败到修复后通过，已有复用候选测试保持通过。
5. 使用者能通过 README 中的提示词和命令开始使用，并理解工具与 AI 的职责边界。
